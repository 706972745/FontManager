1. 设计令牌

1.1 颜色（速览专用，--qb-*）

速览不直接用主界面的 --canvas / --text-*：它是「纸与墨」的极简单列，靠 1px 发丝线分栏， 底色要比完整界面更中性，层级只靠字号与字重。

令牌深色（默认）浅色用途
--qb-bg#111110#FAFAF8窗口底色
--qb-fg#F2F2EF#141412主文字：族名、预览样张、空态标题
--qb-fg-2#9A9A94#6B6B66次文字：许可、字体数、元信息、键帽、操作引导
--qb-fg-3#666660#9B9B95弱文字：版权原文、占位符、尺寸标注
--qb-hair#2A2A27#E2E2DD发丝线、键帽描边
--qb-hair-strong#3A3A36#D2D2CC只给键帽描边（1x 屏可辨，约 2:1）
--qb-hover#1C1C1A#F1F1ED悬停底色
--qb-anchor#3A3A36#D2D2CC行首锚点·静止
--qb-anchor-hover#9A9A94#9B9B95行首锚点·悬停
--qb-accent#5B8CFF#1B4FE0唯一强调色：锚点选中、焦点、链接

用色原则：整屏只有一个强调色（--qb-accent），且只出现在「当前行」和可点链接上； 其余一切靠中性灰阶 + 字号字重分层。

2.8 可访问性

  • 行是 role="button" + tabIndex=0，Enter / Space 可复制；子控件负责自己的键盘事件
  • 折叠提示行同样是 role="button"：键盘用户必须能把它叫出来
  • 焦点态用行首锚点（96px 蓝线）表达，不依赖底色
  • 许可等关键状态用次文字色（≥ 4.5:1），弱文字只给版权原文、占位符这类非关键内容
  • 所有过渡在 prefers-reduced-motion 与「减弱动态效果」下短路

3.16 惯性滚动（1.8.5，全局）

Windows 的 WebView2 没有滚轮惯性：滚一格走一格、松手就停。1.8.5 起由 src/lib/momentumScroll.ts 统一接管所有可滚动容器（动态查找「真的能竖着滚」的祖先， 不维护选择器清单，新增界面自动生效）。

模型：目标位置与视觉位置分开。 滚轮只推「目标」，惯性作用在目标上，视觉位置每帧去追目标 再写 scrollTop。这一点是手感的关键 —— 直接「把这一格写进 scrollTop」等于硬跳一格 （Windows 滚轮一格 100px），滑行只是跳完的尾巴，看起来就是一跳一跳。

参数值含义
GAIN2.2一格滚轮（px）换来的初速度（px/s）。扣掉停机阈值后实际再滑约 40px
DECAY4.2 /s速度按 v *= e^(-DECAY·dt) 衰减，时间常数 ≈ 0.24s
MIN_VELOCITY55 px/s低于它就停。不能更小：scrollTop 在 100% 缩放下按整数存，十几 px/s 时一帧只写 0.2px，量化成 0/1 交替（「一格一格蹭」）
MAX_VELOCITY6500 px/s连甩时的上限
SMOOTH50 → 18 /s视觉位置追目标的系数，按差距自适应（差 ≤0 起点用 50、差 ≥80px 用 18）。小差距两帧到位，不加延迟
MAX_RENDER_SPEED2000 px/s单帧位移上限（60fps 下约 32px）。连甩十几格时目标会领先上千像素，没这条第一帧就跳一大段
RAMP80 ms起步渐入：从静止接上滚轮时线性升到全速，挡掉「第一帧就跳满」
SNAP2.5 px尾差阈值，剩余差距小于它一次到位（不为 1~2px 再磨两三帧）
LINE_PX16deltaMode = 1（按行）时一行的像素估值；deltaMode = 2（按页）= 容器高度
TAIL_RAMP12 → 48小分量折扣：≤12px 完全不给尾速、≥48px 给满额，中间线性过渡。挡的是「触控板小碎步 + 系统自带惯性」叠在一起发飘；鼠标一格（100 上下）永远是满额

行为约定：

  • 顺滑不跳：一格 100px 不是一帧写进去，而是铺成约 20 帧、单帧峰值 21px；

连甩 20 格时单帧封顶 32px（上限生效），视觉是连续滚动而非「跳一格」； - 跟手：小位移（触控板 8px 碎步）追赶系数拉到 50/s，三帧内到位，不加可感知延迟； - 越快越远：一格 100px 实测「100 → 落定 141」（24 帧）；连甩 5 格「500 → 758」； 连甩 20 格「2000 → 3070」；慢滚 8px「8 → 8」（一点都不滑，符合「滚得慢可以不滑」）； - 反向干脆：滚下去还没停就往上滚时，旧方向的动量直接清零，不会先被往反方向拽一下； - 到底交还原生：容器已到头还继续滚时不 preventDefault，交给浏览器做连锁滚动， overscroll-behavior: contain 仍然说了算（设置面板滚到底不会带走背后的列表）； - 一律放行：input / textarea / select / contenteditable 内的滚轮、Ctrl / ⌘ / Alt + 滚轮 （调预览字号）、|deltaX| > |deltaY| 的横向滚动； - 任何真实输入立刻停滑：鼠标按下（含拖滚动条）、翻页键、触摸； - 减法：「减少动态效果」或系统 prefers-reduced-motion 生效时整条关闭，回到原生「滚多少走多少」； - 退出开关：任意元素加 data-momentum="off"（或 上全局关）即可退出接管。

未覆盖：插件面板是独立 WebView 加载插件仓自带的 panel.html，滚动逻辑在主程序里管不到； 插件若需要同样手感，得在自己的面板里实现。

9.1 .compare-panel 生效圆角曾是 8px，应为 12px

现象 对比浮层（.compare-panel）四角实际是 8px，但按 R8「面板归 12」应是 12px， 且与设置面板 / 命令面板（均 12px）弧度不一致 —— 肉眼能看出对比浮层「更方」。

位置内容说明
