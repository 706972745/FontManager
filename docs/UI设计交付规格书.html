1. 设计令牌

1.1 颜色（速览专用，--qb-*）

速览不直接用主界面的 --canvas / --text-*：它是「纸与墨」的极简单列，靠 1px 发丝线分栏， 底色要比完整界面更中性，层级只靠字号与字重。

令牌深色（默认）浅色用途
--qb-bg#111110#FAFAF8窗口底色
--qb-fg#F2F2EF#141412主文字：族名、预览样张、空态标题
--qb-fg-2#9A9A94#6B6B66次文字：许可、字体数、元信息、键帽、操作引导
--qb-fg-3#666660#9B9B95弱文字：版权原文、占位符、尺寸标注
--qb-hair#2A2A27#E2E2DD发丝线、键帽描边
--qb-hair-strong#3A3A36#D2D2CC只给键帽描边（1x 屏可辨，约 2:1）
--qb-hover#1C1C1A#F1F1ED悬停底色
--qb-anchor#3A3A36#D2D2CC行首锚点·静止
--qb-anchor-hover#9A9A94#9B9B95行首锚点·悬停
--qb-accent#5B8CFF#1B4FE0唯一强调色：锚点选中、焦点、链接

用色原则：整屏只有一个强调色（--qb-accent），且只出现在「当前行」和可点链接上； 其余一切靠中性灰阶 + 字号字重分层。

层级字号 / 字重用在哪
主样张8–96px（八档，默认 32）行内预览文字，唯一主角
标签11px / 600族名
状态11px / 500「已启用」标签、折叠态「速览已收起」

  • UI 字体：--font-ui（Inter → 系统中文字体）
  • 等宽字体：--font-mono（JetBrains Mono）—— 只用于数字（启用数、字号读数、统计、键帽）
  • 数字一律 font-variant-numeric: tabular-nums：166 → 165 时右侧控件不横向抖动

1.3 字号档位

SIZES = [8, 14, 18, 24, 32, 48, 64, 96]   // 默认 32（1.6.2 起；此前 24）
  • 卡片 / 列表 / 速览共用同一个 sizeIndex：拨动任意一处，另一处同步
  • 「样张」视图另有 specimenSizeIndex，默认 32，可下探到 8
  • 速览内 Ctrl + 滚轮 调档，不触发 WebView2 页面缩放

2. 速览界面（QuickBar）

按 Alt + `（热键可在设置里改）切换；拖回屏幕顶边则折叠成提示带 → 细线。

2.1 窗口

项规格
默认尺寸420 × 992（逻辑像素），高度按当前显示器可用高度收敛
最小尺寸由右键菜单尺寸推导：菜单宽 × 1.5，并补 16px 外框余量
圆角--qb-radius = 8 物理像素 ÷ DPR；四个阶段全程常开，不收角
描边1px --qb-hair
阴影无
底色--qb-bg；收成细线（bar）时底色与描边一起转透明
圆角为什么必须常开：展开瞬间 docked 变 false，若只在收起态写圆角，系统圆角要等 IPC 往返才回来，中间几帧窗口是直角 —— 就是「展开时四角闪一下」。

2.2 顶栏三段（共 120px）

段高内容底部
第一段56px「已启用」标签（11px，固定 44px 宽）+ 启用数（13px 等宽）+ 搜索（下划线式）+ 四个窗口动作1px 发丝线

  • 搜索框与预览输入都是下划线式（无框、无底色、无圆角）：border-bottom: 1px --qb-hair，

聚焦时转为 --qb-accent - 搜索框可一直压到 48px：窗口很窄时先让搜索缩，不许把右侧四个窗口动作挤出去 - 窗口动作顺序：图钉（自动收起）/ 完整界面 / 最小化 / 关闭；全部沿用原有图标资源，未重绘

2.3 列表行

  • 420 宽时浏览器实测列宽：32 / 44 / 166 / 62 / 18 / 28

2.3.1 行首定位锚点（三态）

状态形态颜色
静止6px 圆点（行首 +24，顶端 17px）--qb-anchor
悬停2 × 80px 竖线--qb-anchor-hover

2.4 就地展开字重（› N）

  • 字重列表从内容列（第三列）起，铺到右边界，位于行网格的第二行
  • 与完整界面卡片里的字重行是同一个组件、同一套样式（.face-line*）
  • 字重名 11px，行高 1.3，单行省略；行尾依次是：归属芯片 → 预览按钮 → 启用开关（睁眼/闭眼）
  • 窄档（≤400px）时网格变 5 列，字重列表改为从第二列起 —— 它与 Aa 列同宽，视觉上仍对齐内容起点

2.5 折叠态（拖回屏幕顶边）

三阶段，全部由 src/lib/useQuickbarDock.ts 驱动，CSS 只负责表现：

2.8 可访问性

  • 行是 role="button" + tabIndex=0，Enter / Space 可复制；子控件负责自己的键盘事件
  • 折叠提示行同样是 role="button"：键盘用户必须能把它叫出来
  • 焦点态用行首锚点（96px 蓝线）表达，不依赖底色
  • 许可等关键状态用次文字色（≥ 4.5:1），弱文字只给版权原文、占位符这类非关键内容
  • 所有过渡在 prefers-reduced-motion 与「减弱动态效果」下短路

6. 维护约定

  1. 代码是唯一事实来源，本文档是它的说明书。改样式就改这里，两边不一致以代码为准并补齐文档。
  2. 速览样式集中在 src/app.css 的 /* ─── 速览界面 ─── */ 段（.qb-*），

设计令牌是同文件顶部的 --qb-* 变量；字阶在 src/design/tokens.css； 窗口尺寸与折叠常量在 src/state/fontStore.ts（QUICKBAR_WIDTH）与 src/lib/useQuickbarDock.ts。 3. 媒体查询的顺序是有意义的：改窄档规则时，必须让它排在对应组件的基础规则之后， 否则同优先级下会被覆盖（1.6.3 就栽在这里）。 4. 文案一律走 src/locales/*.json，不要在组件里硬编码；新增 key 要同步 9 种语言。 5. 图标沿用现有 lucide 资源，不重绘、不换线宽。 6. HTML 版（docs/UI设计交付规格书.html）由 python docs/make-spec-html.py 从本文生成， 给设计师直接在浏览器里看、也能打印成 PDF。改完本文跑一次脚本即可，不要手工改 HTML。
