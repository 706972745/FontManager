## 1. 设计令牌

### 1.1 颜色（速览专用，`--qb-*`）

速览不直接用主界面的 `--canvas` / `--text-*`：它是「纸与墨」的极简单列，靠 1px 发丝线分栏，
底色要比完整界面更中性，层级只靠字号与字重。

| 令牌 | 深色（默认） | 浅色 | 用途 |
|---|---|---|---|
| `--qb-bg` | `#111110` | `#FAFAF8` | 窗口底色 |
| `--qb-fg` | `#F2F2EF` | `#141412` | 主文字：族名、预览样张、空态标题 |
| `--qb-fg-2` | `#9A9A94` | `#6B6B66` | 次文字：许可、字体数、元信息、键帽、操作引导 |
| `--qb-fg-3` | `#666660` | `#9B9B95` | 弱文字：版权原文、占位符、尺寸标注 |
| `--qb-hair` | `#2A2A27` | `#E2E2DD` | 发丝线、键帽描边 |
| `--qb-hair-strong` | `#3A3A36` | `#D2D2CC` | 只给键帽描边（1x 屏可辨，约 2:1） |
| `--qb-hover` | `#1C1C1A` | `#F1F1ED` | 悬停底色 |
| `--qb-anchor` | `#3A3A36` | `#D2D2CC` | 行首锚点·静止 |
| `--qb-anchor-hover` | `#9A9A94` | `#9B9B95` | 行首锚点·悬停 |
| `--qb-accent` | `#5B8CFF` | `#1B4FE0` | 唯一强调色：锚点选中、焦点、链接 |

**用色原则**：整屏只有一个强调色（`--qb-accent`），且只出现在「当前行」和可点链接上；
其余一切靠中性灰阶 + 字号字重分层。

### 1.2 字阶与字体

| 层级 | 字号 / 字重 | 用在哪 |
|---|---|---|
| 主样张 | 8–96px（八档，默认 **32**） | 行内预览文字，唯一主角 |
| 标签 | 11px / 600 | 族名 |
| 状态 | 11px / 500 | 「已启用」标签、折叠态「速览已收起」 |
| 说明 | 13px | 搜索输入、预览文字输入、启用数、空态 |
| 微字 | 9px | 版权、许可、元信息、键帽、折叠态操作引导 |

- UI 字体：`--font-ui`（Inter → 系统中文字体）
- 等宽字体：`--font-mono`（JetBrains Mono）—— 只用于**数字**（启用数、字号读数、统计、键帽）
- 数字一律 `font-variant-numeric: tabular-nums`：166 → 165 时右侧控件不横向抖动

### 1.3 字号档位

```
SIZES = [8, 14, 18, 24, 32, 48, 64, 96]   // 默认 32（1.6.2 起；此前 24）
```

- 卡片 / 列表 / 速览**共用同一个** `sizeIndex`：拨动任意一处，另一处同步
- 「样张」视图另有 `specimenSizeIndex`，默认 32，可下探到 8
- 速览内 `Ctrl + 滚轮` 调档，不触发 WebView2 页面缩放

## 2. 速览界面（QuickBar）

按 `Alt` + &#96;（热键可在设置里改）切换；拖回屏幕顶边则折叠成提示带 → 细线。

### 2.1 窗口

| 项 | 规格 |
|---|---|
| 默认尺寸 | 420 × 992（逻辑像素），高度按当前显示器可用高度收敛 |
| 最小尺寸 | 由右键菜单尺寸推导：菜单宽 × 1.5，并补 16px 外框余量 |
| 圆角 | `--qb-radius` = 8 物理像素 ÷ DPR；**四个阶段全程常开**，不收角 |
| 描边 | 1px `--qb-hair` |
| 阴影 | **无** |
| 底色 | `--qb-bg`；收成细线（`bar`）时底色与描边一起转透明 |

> 圆角为什么必须常开：展开瞬间 `docked` 变 false，若只在收起态写圆角，系统圆角要等
> IPC 往返才回来，中间几帧窗口是直角 —— 就是「展开时四角闪一下」。

### 2.2 顶栏三段（共 120px）

| 段 | 高 | 内容 | 底部 |
|---|---|---|---|
| 第一段 | 56px | 「已启用」标签（11px，固定 44px 宽）+ 启用数（13px 等宽）+ 搜索（下划线式）+ 四个窗口动作 | 1px 发丝线 |
| 第二段 | 40px | 预览文字输入（13px）+ 小 A + 字号滑条 + 大 A + 字号读数 + 筛选 | 1px 发丝线 |
| 第三段（元信息） | 24px | 左：`已显示 / 总数 · 排序名`；右：`8–96 PX`；9px 等宽，字距 0.08em | 1px 发丝线 |

- 搜索框与预览输入都是**下划线式**（无框、无底色、无圆角）：`border-bottom: 1px --qb-hair`，
  聚焦时转为 `--qb-accent`
- 搜索框可一直压到 48px：窗口很窄时先让搜索缩，不许把右侧四个窗口动作挤出去
- 窗口动作顺序：图钉（自动收起）/ 完整界面 / 最小化 / 关闭；全部沿用原有图标资源，未重绘

### 2.3 列表行

**网格**（`display: grid`，无 gap，列宽如下）：

```
32px | 44px | minmax(0,1fr) | 62px | 18px | 28px
 锚点   Aa      族名/预览/版权   许可    ★      › N
```

- 行内边距：`14px 24px 10px`；基准行高 **112px**
- 420 宽时浏览器实测列宽：`32 / 44 / 166 / 62 / 18 / 28`
- 中间列是唯一的弹性列：窗口变宽只有它伸缩，右侧状态列永远在同一条竖线上
- 行底发丝线：左右各内缩 24px，与顶栏三段的分隔线对齐
- 屏幕上不可见的行跳过布局与绘制（`content-visibility: auto`），千级列表滚动才不卡

**各列规格**

| 列 | 元素 | 规格 |
|---|---|---|
| 1 | 定位锚点 | 见 2.3.1 |
| 2 | `Aa` 字形列 | 13px / 400 / `--qb-fg-2`，不跟随字体本身 |
| 3 | 族名 | 11px / 600 / `--qb-fg`，单行省略；**用界面字体，不跟随字体本身** |
| 3 | 预览样张 | 当前字号档（默认 32px）、行高 1.15、`min-height: 46px`；右缘 86% 处渐隐 |
| 3 | 归属芯片 | 标签 / 快照 / 分组，复用主界面 `member-chip`，最大宽 150px |
| 3 | 版权原文 | 9px / `--qb-fg-3`，单行省略，完整内容走悬停提示 |
| 4 | 许可 | 9px / `--qb-fg-2`（不是三级灰：这是要读的状态），过期时加 `lic-expired` |
| 5 | 收藏 ★ | 24×24 热区（图标 12px），未收藏为线态 `--qb-fg-3`，已收藏为填充 + 评级数字 |
| 6 | `› N` | 11px，右对齐到距右边缘 24px；`N` 是可用字重数，窄域显示 `1/4` |

#### 2.3.1 行首定位锚点（三态）

| 状态 | 形态 | 颜色 |
|---|---|---|
| 静止 | 6px 圆点（行首 +24，顶端 17px） | `--qb-anchor` |
| 悬停 | 2 × 80px 竖线 | `--qb-anchor-hover` |
| 点中 / 键盘焦点 | 2 × 96px 竖线 | `--qb-accent` |

- 三态共用同一生长起点（x=26，行首 +16），靠 `scaleY` 生长，走合成器、不重排
- 长度与颜色**双重编码**：色觉障碍下靠长度也能区分
- `prefers-reduced-motion: reduce` 或设置里「减弱动态效果」时直接切终态

#### 2.3.2 行状态

| 状态 | 表现 |
|---|---|
| 静止 | 0 卡片、0 边框、0 阴影，只有行底发丝线 |
| 悬停 | 锚点长成灰线 + 整行 2% 墨色底（`--qb-hover`） |
| 点中 / 焦点 | 锚点转为 96px 蓝线；**不叠底色、不加蓝框、不加左侧标条** |
| 按下 | 底色再加一档（5% 墨），整行不位移 |
| 复制成功 | 族名后就地出现 `· 已复制`，1.5s 淡出（同时保留原 toast） |

> 速览**不显示**启用/停用开关：这里只列已启用字重，放个停用等于误触陷阱。
> 该开关属于完整界面的卡片/列表（见第 3 节）。

### 2.4 就地展开字重（`› N`）

- 字重列表从**内容列（第三列）**起，铺到右边界，位于行网格的第二行
- 与完整界面卡片里的字重行是同一个组件、同一套样式（`.face-line*`）
- 字重名 11px，行高 1.3，单行省略；行尾依次是：归属芯片 → 预览按钮 → 启用开关（睁眼/闭眼）
- 窄档（≤400px）时网格变 5 列，字重列表改为从**第二列**起 —— 它与 Aa 列同宽，视觉上仍对齐内容起点

### 2.5 折叠态（拖回屏幕顶边）

三阶段，全部由 `src/lib/useQuickbarDock.ts` 驱动，CSS 只负责表现：

| 阶段 | 窗口高 | 可见内容 | 进入方式 |
|---|---|---|---|
| `hint` | **34px** | 抓手条 12px + 提示行 20px + 上下描边 2px | 拖到屏幕顶边 |
| `retract` | 过渡 | 提示行上滑出屏、底色转透明 | `hint` 停留 **1000ms** 后 |
| `bar` | **12px** | 顶部 **5px** 实心横线，其余透明（给指针当靶子） | `retract` 结束 |

- 顶边感应：**3px**（前端常量与原生 sensor 必须一起改）
- 抓手线：静止 46 × 1px，收起后摊成 100% × 5px，颜色 `rgba(138,138,143,.62→.85)`
  —— 用中性灰而非主题墨色，因为它浮在桌面上，跟随主题会隐形

#### 2.5.1 提示行（`hint` 阶段）

| 元素 | 规格 |
|---|---|
| 布局 | 两端对齐，左右各 24px |
| 状态「速览已收起」 | 11px / 500 / `--qb-fg`，起点 x=24 |
| 操作「靠近或按 `Alt` + &#96; 展开」 | 9px / `--qb-fg-2`，右缘对齐 x=474（498 宽时） |
| 键帽 | `Alt` 22×16、&#96; 18×16；1px **`--qb-hair-strong`** 描边（浅 `#D2D2CC` / 深 `#3A3A36`）、3px 圆角、9px 等宽 |
| 「+」 | 普通文本，不做成键帽 |
| 文案 | `quickbar.collapsedHint`，`{hotkey}` 由设置里的快捷键决定，**不写死** |

- 文案按各语言自带的分隔符（`·` 或 `—`）在渲染时拆成两段，分隔符本身不显示；
  9 个语言包共用一套逻辑，长文案只收右端并省略，左端状态永远完整
- 键帽用 `inline-block` + baseline 对齐（`inline-flex` 会把盒内文字的基线换掉，整体低 3px）

### 2.6 响应式

| 窗口宽 | 表现 |
|---|---|
| > 400px | 6 列全显示（含 `Aa` 字形列） |
| ≤ 400px | 5 列：`Aa` 列收起，内容起点从 100 左移到 56，字重列表同步改为从第 2 列起 |
| 默认 420px | 落在「6 列」一侧 —— **默认一定看得到 `Aa` 列** |

> 断点 400 比默认宽度 420 低一档：400 正好压在断点上时（`max-width` 含等号），
> 一打开速览就是窄档，等于默认就看不到 `Aa`。

### 2.7 交互地图（速览）

| 操作 | 结果 |
|---|---|
| 点族名 / `Enter` / `Space` | 复制族名，就地提示「已复制」 |
| `› N` | 就地展开 / 收起字重列表 |
| 悬停字重行 | 上方预览临时改用该字重 |
| ★ | 收藏；再次点击弹出评分（1–5） |
| 右键 | 上下文菜单（复制 / 收藏 / 标签 / 快照 / 停用 / 定位文件…） |
| `Tab` | 在「已启用 / 全部」之间切范围 |
| `Esc` | 有输入先清空，再按一次退出速览 |
| `Ctrl + 滚轮` | 调预览字号档 |
| 拖窗口 / 拖回顶边 | 移动 / 折叠 |
| 热键 | 展开 ↔ 折叠 |

### 2.8 可访问性

- 行是 `role="button"` + `tabIndex=0`，`Enter` / `Space` 可复制；子控件负责自己的键盘事件
- 折叠提示行同样是 `role="button"`：键盘用户必须能把它叫出来
- 焦点态用行首锚点（96px 蓝线）表达，不依赖底色
- 许可等**关键状态**用次文字色（≥ 4.5:1），弱文字只给版权原文、占位符这类非关键内容
- 所有过渡在 `prefers-reduced-motion` 与「减弱动态效果」下短路

| 强调色 | 走 R7 §1 的**备选口径亮蓝**，实现里直接复用 `--ui-accent`（#5B8CFF），不引入第二种蓝；切纯灰白只需改 `--pl-accent` / `--pl-knob` 两行 |

> 见 §4 与《UI待定问题清单》A13 / B18。

### 3.13 插件设置面板 · 独立窗口（已落地 1.7.6 / font-sync 0.8.16）

插件自己写的设置页（`FontManager-Plugin` 仓 `font-sync/panel.html`）由主程序开一个
独立窗口加载（`http://127.0.0.1:<port>/panel.html`，见 `plugins.rs`）。它和主窗口
并排出现在同一块屏幕上，所以**必须共用同一套令牌**：

| 项 | 规格 |
|---|---|
| 底色 | 浅 `#fafaf8` / 深 `#111110`（= `--qb-bg`） |
| 文字 | 主 `#141412` / `#f2f2ef`；次 `#6b6b66` / `#9a9a94`；弱 `#9b9b95` / `#666660` |
| 发丝线 | `#e2e2dd` / `#2a2a27`；控件描边 `#d2d2cc` / `#3a3a36` |
| 强调色 | `#1b4fe0` / `#5b8cff`（= `--qb-accent`），只标「当前」与「注意」 |
| 字阶 | 13 正文 / 12.5 段落 / 11.5 次要 / 10.5 表头 / 9 代码徽标 |
| 分区 | 卡片不是「圆角 + 投影」，是**发丝线分栏**；序号退成等宽小字 + 竖发丝线 |
| 页签 | 0 圆角，选中项 **2px 蓝下划线**（与侧栏 2px 蓝竖线同一语言） |
| 控件 | 输入框 / 按钮统一 **30 高、2px 圆角、1px 描边**；主按钮实心蓝，其余发丝描边 |
| 提示块 | 左侧 **2px 竖条**：普通说明不铺底、蓝色=请注意、红色=会出错 |
| 进度 | 3px 圆角轨 + 强调色填充（同插件分区里运行时下载那条） |
| 主题 | 跟系统，且支持 `<html data-theme>` 强制；主程序打开窗口时按 `prefs.themePref` 下发 |

> 面板的样式在插件仓里，改它不需要重发主程序；只有「主题下发」这一侧在主程序（1.7.6）。

## 4. 与早期设计稿的偏离（已实现，本文档为准）

设计稿是提案，落地时按「实际能不能用」做了几处调整。**本文档这些条目是最终口径。**

| 项 | 设计稿 | 实际实现 | 原因 |
|---|---|---|---|
| 96px 预览档 | 固定 46px 高，裁字 | 行高随字号增高（96px 档约 120px），全表仍等齐 | 裁到 46px 只剩字形中间一条带子，放大就失去意义 |
| 窄档断点 | 420px | **400px** | 默认宽 420，断点写 420 会把默认宽度也切进窄档 |
| 速览默认宽度 | 498 × 1238 | **420 × 992** | 沿用既有窗口尺寸，只调离窄档边界；高度按屏幕收敛 |
| 行悬停「停用开关显形」 | 要求 | 速览**不做**，改到完整界面卡片 | 速览只列已启用字重，停用是误触陷阱 |
| 折叠细线换色 / 指针转蓝 | 建议 | **未采纳** | 手抓线保持既有中性灰：它浮在桌面上，跟主题或强调色都会破坏辨识 |
| 键帽字体 | Geist Mono | 项目既有等宽（JetBrains Mono） | 不为几枚键帽引入第三套字体 |
| 插件分区开关 | R7：34×19 | 代码本就是 34×19（`--pill-w/--pill-h`） | 之前记的「30×16」是旧文案，实际一直一致 |
| 在线库小卡 | 304×96、1px 描边、**0 圆角**、卡内无锚点 | **8px 圆角** + 1px 描边 + 行首锚点；族名与小字同为 22 缩进（距左缘 37） | 小卡是网格里的独立卡片而非整行，方角像裁出来的贴片；行首锚点是全软件统一的位置标记，悬停生长反馈也要一致 |

## 6. 维护约定

1. **代码是唯一事实来源**，本文档是它的说明书。改样式就改这里，两边不一致以代码为准并补齐文档。
2. 速览样式集中在 `src/app.css` 的 `/* ─── 速览界面 ─── */` 段（`.qb-*`），
   设计令牌是同文件顶部的 `--qb-*` 变量；字阶在 `src/design/tokens.css`；
   窗口尺寸与折叠常量在 `src/state/fontStore.ts`（`QUICKBAR_WIDTH`）与 `src/lib/useQuickbarDock.ts`。
3. **媒体查询的顺序是有意义的**：改窄档规则时，必须让它排在对应组件的基础规则**之后**，
   否则同优先级下会被覆盖（1.6.3 就栽在这里）。
4. 文案一律走 `src/locales/*.json`，不要在组件里硬编码；新增 key 要同步 9 种语言。
5. 图标沿用现有 lucide 资源，不重绘、不换线宽。
