## 1. 设计令牌

### 1.1 颜色（速览专用，`--qb-*`）

速览不直接用主界面的 `--canvas` / `--text-*`：它是「纸与墨」的极简单列，靠 1px 发丝线分栏，
底色要比完整界面更中性，层级只靠字号与字重。

| 令牌 | 深色（默认） | 浅色 | 用途 |
|---|---|---|---|
| `--qb-bg` | `#111110` | `#FAFAF8` | 窗口底色 |
| `--qb-fg` | `#F2F2EF` | `#141412` | 主文字：族名、预览样张、空态标题 |
| `--qb-fg-2` | `#9A9A94` | `#6B6B66` | 次文字：许可、字体数、元信息、键帽、操作引导 |
| `--qb-fg-3` | `#666660` | `#9B9B95` | 弱文字：版权原文、占位符、尺寸标注 |
| `--qb-hair` | `#2A2A27` | `#E2E2DD` | 发丝线、键帽描边 |
| `--qb-hair-strong` | `#3A3A36` | `#D2D2CC` | 只给键帽描边（1x 屏可辨，约 2:1） |
| `--qb-hover` | `#1C1C1A` | `#F1F1ED` | 悬停底色 |
| `--qb-anchor` | `#3A3A36` | `#D2D2CC` | 行首锚点·静止 |
| `--qb-anchor-hover` | `#9A9A94` | `#9B9B95` | 行首锚点·悬停 |
| `--qb-accent` | `#5B8CFF` | `#1B4FE0` | 唯一强调色：锚点选中、焦点、链接 |

**用色原则**：整屏只有一个强调色（`--qb-accent`），且只出现在「当前行」和可点链接上；
其余一切靠中性灰阶 + 字号字重分层。

### 1.2 字阶与字体

| 层级 | 字号 / 字重 | 用在哪 |
|---|---|---|
| 主样张 | 8–96px（八档，默认 **32**） | 行内预览文字，唯一主角 |
| 标签 | 11px / 600 | 族名 |
| 状态 | 11px / 500 | 「已启用」标签、折叠态「速览已收起」 |
| 说明 | 13px | 搜索输入、预览文字输入、启用数、空态 |
| 微字 | 9px | 版权、许可、元信息、键帽、折叠态操作引导 |

- UI 字体：`--font-ui`（Inter → 系统中文字体）
- 等宽字体：`--font-mono`（JetBrains Mono）—— 只用于**数字**（启用数、字号读数、统计、键帽）
- 数字一律 `font-variant-numeric: tabular-nums`：166 → 165 时右侧控件不横向抖动

### 1.3 字号档位

```
SIZES = [8, 14, 18, 24, 32, 48, 64, 96]   // 默认 32（1.6.2 起；此前 24）
```

- 卡片 / 列表 / 速览**共用同一个** `sizeIndex`：拨动任意一处，另一处同步
- 「样张」视图另有 `specimenSizeIndex`，默认 32，可下探到 8
- 速览内 `Ctrl + 滚轮` 调档，不触发 WebView2 页面缩放

## 2. 速览界面（QuickBar）

按 `Alt` + &#96;（热键可在设置里改）切换；拖回屏幕顶边则折叠成提示带 → 细线。

### 2.1 窗口

| 项 | 规格 |
|---|---|
| 默认尺寸 | 472 × 992（逻辑像素），高度按当前显示器可用高度收敛 |
| 最小尺寸 | 由右键菜单尺寸推导：菜单宽 × 1.5 并补 16px 外框余量，**再与默认宽度取大者**（样张列不得窄于 240px） |
| 圆角 | `--qb-radius` = 8 物理像素 ÷ DPR；**四个阶段全程常开**，不收角 |
| 描边 | 1px `--qb-hair` |
| 阴影 | **无** |
| 底色 | `--qb-bg`；收成细线（`bar`）时底色与描边一起转透明 |

> 圆角为什么必须常开：展开瞬间 `docked` 变 false，若只在收起态写圆角，系统圆角要等
> IPC 往返才回来，中间几帧窗口是直角 —— 就是「展开时四角闪一下」。

### 2.2 顶栏三段（共 120px）

| 段 | 高 | 内容 | 底部 |
|---|---|---|---|
| 第一段 | 56px | 「已启用」标签（11px，固定 44px 宽）+ 启用数（13px 等宽）+ 搜索（下划线式）+ 四个窗口动作 | 1px 发丝线 |
| 第二段 | 40px | 预览文字输入（13px）+ 小 A + 字号滑条 + 大 A + 字号读数 + 筛选 | 1px 发丝线 |
| 第三段（元信息） | 24px | 左：`已显示 / 总数 · 排序名`；右：`8–96 PX`；9px 等宽，字距 0.08em | 1px 发丝线 |

- 搜索框与预览输入都是**下划线式**（无框、无底色、无圆角）：`border-bottom: 1px --qb-hair`，
  聚焦时转为 `--qb-accent`
- 搜索框可一直压到 48px：窗口很窄时先让搜索缩，不许把右侧四个窗口动作挤出去
- 窗口动作顺序：图钉（自动收起）/ 完整界面 / 最小化 / 关闭；全部沿用原有图标资源，未重绘
- 字号滑条与完整界面顶栏是**同一套控件**（2px 发丝轨道 / 8px 实心蓝点 / 无填充段，见 §3.2），
  速览只把它定宽 **118px**；两端的小 A / 大 A 属第二段的布局元素，不是滑条本体

### 2.3 列表行

**网格**（`display: grid`，无 gap，列宽如下）：

```
32px | 44px | minmax(0,1fr) | 62px | 18px | 28px
 锚点   Aa      族名/预览/版权   许可    ★      › N
```

- 行内边距：`14px 24px 10px`；基准行高 **112px**
- 472 宽时浏览器实测列宽：`32 / 44 / 240 / 62 / 18 / 28`
- 中间列是唯一的弹性列：窗口变宽只有它伸缩，右侧状态列永远在同一条竖线上
- **中间列（样张列）有 240px 的硬下限**：默认宽度 472 时正好 240，窗口再窄就由
  「最小尺寸 = max(菜单推导值, 默认宽度)」兜住 —— 拖不到比样张列下限更窄的地方。
  理由：样张区窄于 240px 就放不下 32px 的一整行默认示例（等宽字体约需 230px），
  `useMarquee` 会被迫开跑马灯，滚到一半的字看着像渲染坏了（见待定清单 A17）
- 行底发丝线：左右各内缩 24px，与顶栏三段的分隔线对齐
- 屏幕上不可见的行跳过布局与绘制（`content-visibility: auto`），千级列表滚动才不卡

**各列规格**

| 列 | 元素 | 规格 |
|---|---|---|
| 1 | 定位锚点 | 见 2.3.1 |
| 2 | `Aa` 字形列 | 13px / 400 / `--qb-fg-2`，不跟随字体本身 |
| 3 | 族名 | 11px / 600 / `--qb-fg`，单行省略；**用界面字体，不跟随字体本身** |
| 3 | 预览样张 | 当前字号档（默认 32px）、行高 1.15、`min-height: 46px`；**向右借道 52px**（`margin-right: -52px`，吃掉「未知」列 62px 中的 52px），右缘停在星级列左缘前 **10px** —— 落在「未知」与「★」之间，且不压星级按钮的 24px 热区（有 −6px 负 margin）；超长时跑马灯 |
| 3 | 归属芯片 | 标签 / 快照 / 分组，复用主界面 `member-chip`，最大宽 150px |
| 3 | 版权原文 | 9px / `--qb-fg-3`，单行省略，完整内容走悬停提示 |
| 4 | 许可 | 9px / `--qb-fg-2`（不是三级灰：这是要读的状态），过期时加 `lic-expired` |
| 5 | 收藏 ★ | 24×24 热区（图标 12px），未收藏为线态 `--qb-fg-3`，已收藏为填充 + 评级数字 |
| 6 | `› N` | 11px，右对齐到距右边缘 24px；`N` 是可用字重数，窄域显示 `1/4` |

#### 2.3.1 行首定位锚点（三态）

| 状态 | 形态 | 颜色 |
|---|---|---|
| 静止 | 6px 圆点（行首 +24，顶端 17px） | `--qb-anchor` |
| 悬停 | 2 × 80px 竖线 | `--qb-anchor-hover` |
| 点中 / 键盘焦点 | 2 × 96px 竖线 | `--qb-accent` |

- 三态共用同一生长起点（x=26，行首 +16），靠 `scaleY` 生长，走合成器、不重排
- 长度与颜色**双重编码**：色觉障碍下靠长度也能区分
- `prefers-reduced-motion: reduce` 或设置里「减弱动态效果」时直接切终态

#### 2.3.2 行状态

| 状态 | 表现 |
|---|---|
| 静止 | 0 卡片、0 边框、0 阴影，只有行底发丝线 |
| 悬停 | 锚点长成灰线 + 整行 2% 墨色底（`--qb-hover`） |
| 点中 / 焦点 | 锚点转为 96px 蓝线；**不叠底色、不加蓝框、不加左侧标条** |
| 按下 | 底色再加一档（5% 墨），整行不位移 |
| 复制成功 | 族名后就地出现 `· 已复制`，1.5s 淡出（同时保留原 toast） |

> 速览**不显示**启用/停用开关：这里只列已启用字重，放个停用等于误触陷阱。
> 该开关属于完整界面的卡片/列表（见第 3 节）。

### 2.4 就地展开字重（`› N`）

- 字重列表从**内容列（第三列）**起，铺到右边界，位于行网格的第二行
- 与完整界面卡片里的字重行是同一个组件、同一套样式（`.face-line*`）
- 字重名 11px，行高 1.3，单行省略；行尾依次是：归属芯片 → 预览按钮 → 启用开关（睁眼/闭眼）
- 窄档（≤400px）时网格变 5 列，字重列表改为从**第二列**起 —— 它与 Aa 列同宽，视觉上仍对齐内容起点

### 2.5 折叠态（拖回屏幕顶边）

三阶段，全部由 `src/lib/useQuickbarDock.ts` 驱动，CSS 只负责表现：

| 阶段 | 窗口高 | 可见内容 | 进入方式 |
|---|---|---|---|
| `hint` | **34px** | 抓手条 12px + 提示行 20px + 上下描边 2px | 拖到屏幕顶边 |
| `retract` | 过渡 | 提示行上滑出屏、底色转透明 | `hint` 停留 **1000ms** 后 |
| `bar` | **12px** | 顶部 **5px** 实心横线，其余透明（给指针当靶子） | `retract` 结束 |

- 顶边感应：**3px**（前端常量与原生 sensor 必须一起改）
- 抓手线：静止 46 × 1px，收起后摊成 100% × 5px，颜色 `rgba(138,138,143,.62→.85)`
  —— 用中性灰而非主题墨色，因为它浮在桌面上，跟随主题会隐形

#### 2.5.1 提示行（`hint` 阶段）

| 元素 | 规格 |
|---|---|
| 布局 | 两端对齐，左右各 24px |
| 状态「速览已收起」 | 11px / 500 / `--qb-fg`，起点 x=24 |
| 操作「靠近或按 `Alt` + &#96; 展开」 | 9px / `--qb-fg-2`，右缘对齐 x=474（498 宽时） |
| 键帽 | `Alt` 22×16、&#96; 18×16；1px **`--qb-hair-strong`** 描边（浅 `#D2D2CC` / 深 `#3A3A36`）、3px 圆角、9px 等宽 |
| 「+」 | 普通文本，不做成键帽 |
| 文案 | `quickbar.collapsedHint`，`{hotkey}` 由设置里的快捷键决定，**不写死** |

- 文案按各语言自带的分隔符（`·` 或 `—`）在渲染时拆成两段，分隔符本身不显示；
  9 个语言包共用一套逻辑，长文案只收右端并省略，左端状态永远完整
- 键帽用 `inline-block` + baseline 对齐（`inline-flex` 会把盒内文字的基线换掉，整体低 3px）

### 2.6 响应式

| 窗口宽 | 表现 |
|---|---|
| > 400px | 6 列全显示（含 `Aa` 字形列） |
| ≤ 400px | 5 列：`Aa` 列收起，内容起点从 100 左移到 56，字重列表同步改为从第 2 列起 |
| 默认 472px | 落在「6 列」一侧 —— **默认一定看得到 `Aa` 列**，样张列也有 240px |

> 断点 400 比默认宽度 472 低两档：400 正好压在断点上时（`max-width` 含等号），
> 一打开速览就是窄档，等于默认就看不到 `Aa`。

### 2.7 交互地图（速览）

| 操作 | 结果 |
|---|---|
| 点族名 / `Enter` / `Space` | 复制族名，就地提示「已复制」 |
| `› N` | 就地展开 / 收起字重列表 |
| 悬停字重行 | 上方预览临时改用该字重 |
| ★ | 收藏；再次点击弹出评分（1–5） |
| 右键 | 上下文菜单（复制 / 收藏 / 标签 / 快照 / 停用 / 定位文件…） |
| `Tab` | 在「已启用 / 全部」之间切范围 |
| `Esc` | 有输入先清空，再按一次退出速览 |
| `Ctrl + 滚轮` | 调预览字号档 |
| 拖窗口 / 拖回顶边 | 移动 / 折叠 |
| 热键 | 展开 ↔ 折叠 |

### 2.8 可访问性

- 行是 `role="button"` + `tabIndex=0`，`Enter` / `Space` 可复制；子控件负责自己的键盘事件
- 折叠提示行同样是 `role="button"`：键盘用户必须能把它叫出来
- 焦点态用行首锚点（占满卡片高度的蓝线）表达，不依赖底色
- 许可等**关键状态**用次文字色（≥ 4.5:1），弱文字只给版权原文、占位符这类非关键内容
- 所有过渡在 `prefers-reduced-motion` 与「减弱动态效果」下短路

## 3. 完整界面（主窗口 · R4/R5 已落地）

> 主窗口已按 R4/R5 重做过一轮（1.7.0–1.7.7），纸墨两色底、单一蓝强调、去玻璃模糊、
> 行首三态锚点、三视图都已落地。**3.1–3.10 的逐项数值已按源码回写**（每条都能在
> `src/app.css` 里找到对应类名），下面是与主界面共用的那套骨架。

### 3.1 窗口与标题栏

主窗口外框与速览**同源**：圆角用 `--qb-radius`（运行期按 DPR 算好写入），
所以两个窗口的弧度永远一致；DWM 那圈系统阴影一并去掉，改由 CSS 画。

| 元素 | 规格 |
|---|---|
| 窗口外框 `.app-frame` | `border-radius: var(--qb-radius, 8px)`；1px 描边；底 `--ui-bg`；`overflow: hidden` |
| 标题栏 `.titlebar` | 高 **40px**；`padding: 0 5px 0 14px`；两端对齐；底部 1px 发丝线；整条 `-webkit-app-region: drag`（可拖窗） |
| 品牌区 `.titlebar-brand` | flex / gap 9px；`pointer-events: none`（点不中，拖窗优先） |
| 品牌标 `.brand-mark` | 21×21；`filter: none`（1.7.3 去掉旧玻璃时代的蓝色光晕） |

### 3.12 在线字体库 · 自身字体渲染与来源（1.7.8）

#### 3.12.1 族名用自身字体渲染

在线库的族名**用那个字族自己的字体显示**（本地库不这么做：本地族的族名是界面字体）。
取字走 Google Fonts 的**字符级子集**接口：

```
GET https://fonts.googleapis.com/css2?family=<族名>&text=<族名用到的字符>
```

- 返回的 CSS 只有一条 `@font-face`，src 指向 `fonts.gstatic.com` 上**只含这几个字**的 woff2
  （实测平均 **335 B**；完整 TTF 平均 46 KB，fontsource 自己的 latin 子集平均 17 KB）。
- 只在卡片**滚进视口**时才取（`IntersectionObserver`，边距 240px）；同屏并发上限 4。
- 族名在 Google 上没有 / 请求失败 → **回退界面字体**，并在列表上方给一行说明
  （`online.selfFontFailed`），**不静默回退**。
- CSP 放行：`connect-src` 加 `fonts.googleapis.com`，`font-src` 加 `fonts.gstatic.com`。

#### 3.12.2 来源行

meta 行末尾原本是一行写死的字符串
`"api.fontsource.org · raw.githubusercontent.com · cdn.jsdelivr.net"`。
1.7.8 拆成三个**独立可点击项**，点一下 = 按该来源筛选，再点一下 = 取消：

| 元素 | 规格 |
|---|---|
| 来源 chip `.online-host` | 等宽 10px、**4px 圆角**、高 **24**、1px `rgba(ink,.08)` 描边、透明底 |
| 选中态 `.online-host-on` | 文字 `--ui-accent`，描边混 40% 蓝，底色混 8% 蓝 |
| 标签 / 打开链接 | 10px 三级灰；「打开 ↗」把当前来源的地址交给系统浏览器 |
| 子集行 `.online-subsets` | 只在镜像源下出现（按 unicode-range 切分是那条通道独有的）；复用 `.online-chip`，选中蓝底白字 |

三个地址的分工：`api.fontsource.org` 是**目录**（族清单与许可证，不含字体文件）、
`raw.githubusercontent.com` 是**原始仓库**（完整字体，直连慢或不通时程序自动走镜像）、
`cdn.jsdelivr.net` 是**镜像**（完整文件 + 按 unicode-range 切好的分片）。

**搜索同时覆盖地址与子集**：搜 `jsdelivr` / `cdn` / `raw` / `github` / `fontsource`
能命中对应来源的族，搜 `vietnamese` 能命中所有含该子集的族（531 个）。

### 3.16 惯性滚动（1.8.5，全局）

Windows 的 WebView2 没有滚轮惯性：滚一格走一格、松手就停。1.8.5 起由
`src/lib/momentumScroll.ts` 统一接管所有可滚动容器（动态查找「真的能竖着滚」的祖先，
不维护选择器清单，新增界面自动生效）。

**模型：目标位置与视觉位置分开。** 滚轮只推「目标」，惯性作用在目标上，视觉位置每帧去追目标
再写 `scrollTop`。这一点是手感的关键 —— 直接「把这一格写进 scrollTop」等于硬跳一格
（Windows 滚轮一格 100px），滑行只是跳完的尾巴，看起来就是一跳一跳。

| 参数 | 值 | 含义 |
|---|---|---|
| `GAIN` | `2.2` | 一格滚轮（px）换来的初速度（px/s）。扣掉停机阈值后实际再滑约 **40px** |
| `DECAY` | `4.2` /s | 速度按 `v *= e^(-DECAY·dt)` 衰减，时间常数 ≈ 0.24s |
| `MIN_VELOCITY` | `55` px/s | 低于它就停。**不能更小**：`scrollTop` 在 100% 缩放下按整数存，十几 px/s 时一帧只写 0.2px，量化成 0/1 交替（「一格一格蹭」） |
| `MAX_VELOCITY` | `6500` px/s | 连甩时的上限 |
| `SMOOTH` | `50 → 18` /s | 视觉位置追目标的系数，按差距自适应（差 ≤0 起点用 50、差 ≥80px 用 18）。小差距两帧到位，不加延迟 |
| `MAX_RENDER_SPEED` | `1400` px/s | **单帧位移上限**（60fps 下约 **23px**）。这个值直接决定「最粗的一步有多粗」，也决定掉一帧时最多多走多少。连甩十几格时目标会领先上千像素，没这条第一帧就跳一大段 |
| `SNAP` | `2.5` px | 尾差阈值，剩余差距小于它一次到位（不为 1~2px 再磨两三帧） |
| `LINE_PX` | `16` | `deltaMode = 1`（按行）时一行的像素估值；`deltaMode = 2`（按页）= 容器高度 |
| `TAIL_RAMP` | `12 → 48` | 小分量折扣：≤12px 完全不给尾速、≥48px 给满额，中间线性过渡。挡的是「触控板小碎步 + 系统自带惯性」叠在一起发飘；鼠标一格（100 上下）永远是满额 |

行为约定：

- **顺滑不跳**：一格 100px 不是一帧写进去，而是铺成 **24 帧**、单帧峰值 **23px**，
  逐帧位移 `23, 21, 20, 19, 15, 10, 6, 5, 3, 2, 2, 2…` —— **单调递减，没有加速段**。
  连甩 20 格时单帧封顶 23px，视觉是连续滚动而非「跳一格」；
- **没有「起步渐入」**（刻意）：试过 80ms 内从零升到全速，第一帧只走 6px、
  随后冲到 21px，那个加速段本身就是卡的来源 —— 滚轮给的是冲量，视觉上第一帧就该最快；
- **跟手**：小位移（触控板 8px 碎步）追赶系数拉到 50/s，三帧内到位，不加可感知延迟；
- **越快越远**：一格 100px 实测「100 → 落定 141」（24 帧）；连甩 5 格「500 → 758」；
  连甩 20 格「2000 → 3070」；慢滚 8px「8 → 8」（一点都不滑，符合「滚得慢可以不滑」）；
- **反向干脆**：滚下去还没停就往上滚时，旧方向的动量直接清零，不会先被往反方向拽一下；
- **到底交还原生**：容器已到头还继续滚时不 `preventDefault`，交给浏览器做连锁滚动，
  `overscroll-behavior: contain` 仍然说了算（设置面板滚到底不会带走背后的列表）；
- **一律放行**：`input / textarea / select / contenteditable` 内的滚轮、`Ctrl / ⌘ / Alt + 滚轮`
  （调预览字号）、`|deltaX| > |deltaY|` 的横向滚动；
- **任何真实输入立刻停滑**：鼠标按下（含拖滚动条）、翻页键、触摸；
- **减法**：「减少动态效果」或系统 `prefers-reduced-motion` 生效时整条关闭，回到原生「滚多少走多少」；
- **退出开关**：任意元素加 `data-momentum="off"`（或 `<html>` 上全局关）即可退出接管。

> 未覆盖：插件面板是独立 WebView 加载插件仓自带的 `panel.html`，滚动逻辑在主程序里管不到；
> 插件若需要同样手感，得在自己的面板里实现。

## 9. 代码勘误（已修复，1.7.8）

> 这一节记的是「代码与自身 R8 规则打架」的地方。文档 §3.14 写得对（面板应是 12），
> 是代码没跟上。

### 9.1 `.compare-panel` 生效圆角曾是 8px，应为 12px

**现象**
对比浮层（`.compare-panel`）四角实际是 **8px**，但按 R8「面板归 12」应是 12px，
且与设置面板 / 命令面板（均 12px）弧度不一致 —— 肉眼能看出对比浮层「更方」。

**根因（`src/app.css`）**

| 位置 | 内容 | 说明 |
|---|---|---|
| L3394 | `.compare-panel { … }` | 旧 `border-radius: 10px` 已在 1.7.7 删掉（块内注释确认，无残留） |
| L7824 | `.compare-panel { border-radius: 12px; … }` | 弹窗族那条，写 12 ✅ |
| L8000 | `.compare-panel, .selection-bar { border-radius: 8px; … }` | **第三批覆盖段**，把 compare-panel 圈进 8px 组 ❌ |
| R8 段 | 注释：「`.compare-panel` 原本就是 12，不重复声明」 | 注释**判断错误** —— 它只看到了 L7824 的 12，漏掉了 L8000 的 8 |

生效判定：L8000（8px）在 L7824（12px）之后，且 R8 段按「原本就是 12 不重复声明」把
compare-panel 排除，于是**没有更晚的 12 覆盖**，最终 **8px 胜出**。
